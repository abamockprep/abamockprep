## 🚀 What is ABA Mock Prep?

**ABA Mock Prep** is an intelligent web-based study platform built specifically for candidates preparing for the **Behavior Analyst Certification Board (BACB®)** examinations:

- **BCBA® (Board Certified Behavior Analyst) — 6th Edition TCO:** Full 185-question, 4-hour timed exam simulation.
- **BCaBA® (Board Certified Assistant Behavior Analyst):** 175-question timed simulation.
- **RBT® (Registered Behavior Technician) — 2026 Standards:** 85-question, 90-minute timed simulation.

---

## ✨ Key Platform Features

### ⏱️ Standardized Pearson VUE Pacing Engine
- Exact time constraints matching testing centers (~78 seconds per question on BCBA; ~63 seconds on RBT).
- Bookmark, strike-through, flag for review, and split-screen clinical scenario layout.

### 🤖 24/7 AI Clinical Tutor
- Real-time explanations on every answer choice using applied behavioral principles (Cooper 3rd Edition standards).
- Explains not only why the correct answer is right, but why each distractor is wrong.

### 🌐 Instant Dual-Language Engine (EN ⇄ ES)
- Seamless 100% paired bilingual routing: switch instantly between English and Spanish without losing test state.
- Crucial for bilingual candidates mastering complex English terminology in Pearson VUE.

### 📄 Itemized Error Diagnostic Workbook Export
- One-click export of missed questions into formatted **Microsoft Word (.docx)** and **Google Docs** study guides.

### 📅 Adaptive Habit Funnel & Countdown Calendar
- **5-Stage Psychological Habit Funnel:**
  1. *Adaptation:* Zero-friction 3-question micro-habits.
  2. *Dependency:* Daily streak protection & Bonus XP rewards.
  3. *Gap Awareness:* Objective blind-spot diagnosis in core domains (B, F, G).
  4. *Guided Mastery:* Structured study solutions.
  5. *Final Urgency:* Timed endurance mocks as test day approaches.
- **Dynamic Time Scales:** Automatically divides the study plan into **Weeks** (>30 days), **Days** (15–30 days), or **Hourly Sprint Blocks** (<15 days).

## 🛠️ Technology Stack (Summary)

- **Frontend & App Router:** Next.js 14, React 18, TypeScript, Tailwind CSS (Monochrome ink/paper theme)
- **Backend & Database:** Supabase (PostgreSQL, Row-Level Security, Edge Functions)
- **AI Engine:** Structured reasoning integration with fallback handling
- **Payments & Billing:** Stripe Checkout & Webhooks (Subscription and One-Time Express Passes)
- **Email Infrastructure:** Resend (CAN-SPAM and RFC 8058 compliant)
